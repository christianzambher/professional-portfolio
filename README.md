# Portafolio Profesional

Sitio web de portafolio personal desarrollado con HTML, CSS, Bootstrap y JavaScript.

## 🚀 Demo

http://portafolioprofesional.s3-website.us-east-2.amazonaws.com/

## 📋 Descripción

Este proyecto consiste en un sitio web estático utilizado para presentar información profesional, habilidades técnicas y proyectos personales.

La aplicación se encuentra desplegada mediante AWS S3 Static Website Hosting.

## 🛠 Tecnologías utilizadas

- HTML5
- CSS3
- Bootstrap
- JavaScript
- jQuery
- AWS S3
